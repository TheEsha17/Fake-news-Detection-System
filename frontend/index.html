The information problem


Information is everywhere. Truth is harder to find.

A false story needs seconds to write and moments to share. A careful correction takes hours, and rarely travels as far. Readers see a headline, a source name and a share count, and must decide almost instantly.


Fabricated stories lean on recognisable habits: urgent language, anonymous authorities, emotional framing and missing detail. Those habits leave measurable traces in the text itself.

The technology


Classical machine learning, measured honestly.

InFact converts text to TF-IDF features and trains four well-understood classifiers: Logistic Regression, Linear SVM, Multinomial Naive Bayes and K-Nearest Neighbors. They are compared on the same held-out test set, and the best by F1-score serves predictions.

What InFact is

A web application that classifies a news article as real or fake using machine learning trained on labelled examples.


Why it matters

Misinformation shapes health decisions, elections and trust in institutions. Tools that flag suspicious writing give readers a prompt to slow down.

Objectives

Build an end-to-end classifier, compare several algorithms fairly, and present honest results in an interface people can use.

Technologies

Python, Flask, scikit-learn, Joblib, HTML, CSS and JavaScript.

Machine learning approach

TF-IDF features (words and word pairs) feed Logistic Regression, Linear SVM, Multinomial Naive Bayes and K-Nearest Neighbors. They are evaluated on a held-out test set; the best F1-score is deployed.

Limitations

  • It judges writing style, not facts. A well-written falsehood can pass; an unusual true story can be flagged.
  • It reflects its training data. Different topics, regions, languages or eras may perform worse than the reported metrics.
  • Satire, opinion and breaking news are hard cases.
  • Use it as one signal, then check primary sources.
